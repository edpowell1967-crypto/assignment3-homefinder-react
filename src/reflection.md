What did you ask Copilot to help you build? How did you break down the problem?
I asked Copilot to help build a home finding app like Zillow. I broke doen the problems based on the functionalities and features of Zillow.
How did your approach to asking questions change as you worked?
I learned to craft the prompts to give me the results I wanted, very detailed prompts are better than ambiguous ones.
What parts of the development process with GitHub Copilot surprised you?
The need to constantly rework the code based on errors found as features were added. 
What did you learn about the technology you used that you didn't know before?
I learned that the CoPilot is very powerful and could pose threats to developers due to the ease of creating applications similar to ones that probably cost millions to create. 
What would you do differently if you had to build this again? 
I would research the target app in more detail before starting the process of copying the idea. This would allow better prompting and better results.
